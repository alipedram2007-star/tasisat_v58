# سیستم مدیریت اطلاعات پرسنل — نسخه وب (FastAPI)

نسخه چندکاربره تحت وب با همان قابلیت‌های برنامه دسکتاپ.

## قابلیت‌ها
- مدیریت اطلاعات شخصی پرسنل (تمام فیلدها)
- **سوپر کلید (کد ملی + شماره اندیکاتور)**: یک فرد با یک کد ملی می‌تواند چند بار با شماره اندیکاتور متفاوت همکاری کند. اندیکاتور کوچکتر به عنوان اندیکاتور اصلی فرد در نظر گرفته می‌شود و رکوردهای دیگر به عنوان سابقه محسوب می‌شوند.
- عکس پرسنلی استاندارد ۳×۴
- مدیریت سوابق کاری با **تمام فیلدهای پرسنل** + تاریخ شروع/پایان و توضیحات کار
- جستجو
- ایمپورت و خروجی اکسل (با پشتیبانی از سوپر کلید)
- تقویم شمسی (ورود تاریخ به صورت `1403/01/15`)
- چندکاربره همزمان از طریق مرورگر
- صدور کارت تردد موقت ویژه پیمانکاران (PDF روی و پشت)
- تولید گروهی کارت: انتخاب چند پرسنل و قرارگیری ۴ نفر در هر برگه A4 ایستاده (portrait)؛ روی و پشت هر کارت روبه‌روی هم در یک سطر

## نصب و اجرا

```bash
cd tasisat_web
pip install -r requirements.txt
python main.py
```

یا:

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

سپس در مرورگر باز کنید:

```
http://localhost:8000
```

برای دسترسی از شبکه محلی (سایر سیستم‌ها):

```
http://IP-آدرس-سرور:8000
```

## API
- `GET  /api/personnel` — لیست / جستجو
- `POST /api/personnel` — ثبت جدید
- `PUT  /api/personnel/{id}` — ویرایش
- `DELETE /api/personnel/{id}` — حذف
- `POST /api/personnel/{id}/photo` — آپلود عکس
- `GET  /api/personnel/{id}/work` — سوابق کاری
- `POST /api/personnel/{id}/work` — افزودن سابقه
- `POST /api/import/excel` — ایمپورت
- `GET  /api/export/excel` — خروجی اکسل
- `GET  /api/personnel/{id}/card` — صدور کارت موقت (PDF)

مستندات تعاملی: `http://localhost:8000/docs`
